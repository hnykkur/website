# Forming location phrases

<!-- G33 · duo-draft · Duolingo Chinese · Screenshot_20260912_003255_Duolingo.jpg -->
Add a **single directional character** after a noun to make a location phrase.

## Direction

| Direction | Meaning |
| --- | --- |
| **里** | inside |
| **外** | outside |
| **上** | on / above |

## Examples

**画儿在墙上。** — The painting is on the wall.

**大门外没有停车场。** — There is no parking lot outside the main gate.

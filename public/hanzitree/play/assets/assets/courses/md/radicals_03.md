# Radicals III

**Radicals III** is the third **guess-the-radical** course: match the **English clue** to the correct **radical form** (including variants like 氵, 扌, 刂).

## New themes

Water, hand, silk/thread, knife, enclosure, table (几), and arrival (至) — components that dominate **everyday** compound characters.

## Same rules as before

**Recognition only** — you never assemble a character from pieces in this mode.

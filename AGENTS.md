## Design goals

- Nordic
- Minimal
- Elegant
- Premium
- Timeless
- Engineering focused

## Avoid

- Startup clichés
- Huge gradients
- Fake testimonials
- Stock photos
- Marketing buzzwords
- Excessive animations

## Technology

- Next.js
- TypeScript
- Tailwind

## Always

- prefer reusable components
- keep code clean
- mobile first
- accessible
- use Server Components whenever possible
